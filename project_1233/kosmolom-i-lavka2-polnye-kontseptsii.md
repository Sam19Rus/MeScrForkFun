## Часть 1. «Космо-лом v2: Ржавый Фрегат» — полная концепция

### 1.1. Питч и название

**Питч (одно предложение):** «Вы — старьёвщик глубокого космоса: высаживайтесь на брошенные корабли, вырезайте ценное до того как кончится кислород, и стройте из трофеев собственный корабль — всё сгоревшее в рейде остаётся там, кроме того, что вы успели вывезти».

Названия (RU / EN, для A/B): «Космо-Лом: Ржавый Фрегат» / «Ржавый Фрегат: Звёздный старьёвщик» / «Разборщик: брошенные корабли» / Star Salvage: Shipbreaker / Rusty Frigate.

**Почему корабль, а не станция (ваш вопрос о вариациях):**
1. Корабль = **транспорт и дом одновременно**: звёздная карта — естественный UI выбора секторов (станция привязана к месту — карта выглядит искусственно).
2. Корабль = **персонаж**: ИИ-напарник на борту даёт голос (обучение, шутки, тревога при нехватке кислорода) — дешёвый нарративный слой с сильным эффектом привязанности (глэдос-эффект [наблюдение]).
3. Корабль **растёт визуально**: новые модули пристраиваются к корпусу — идентичность «мой фрегат» сильнее, чем «моя станция» (он уже ваш, вы в нём летаете).
4. Контент-расширение = **новые сектора карты** (визуализированный прогресс: долетел до туманности).
5. Доказательство темы: Hardspace: Shipbreaker — 500K+ копий за EA+релиз (Focus Entertainment, 06.2022 — факт); FTL/Starbound — «корабль-дом» устойчивая фантазия [наблюдение].

### 1.2. Core loop (сектор-забег 8–12 мин — по вашему решению №3)

```
[ДОК] утренний ритуал: сигнал дня (бесплатный дереликт, сид для всех) + дивиденд витрины
   ↓
[ЗВЁЗДНАЯ КАРТА] выбрать сектор (2–3 доступны): биом + модификаторы видны
   (Пояс обломков: безопасно/бедно · Кладбище флота: дроны/дорого · Замёрзший рубеж: кислород короче/ксено-лут)
   ↓  выбор режима: ПРОГУЛКА (×1.0, теряешь сыпучий груз) / РИСК (×1.5, теряешь всё невылетевшее)
[ДЕРЕЛИКТ 1..3] сетка отсеков 6×8: кислород = бюджет ходов (12–18)
   вскрывать панели: груз / материалы / hazard (радиация −O₂, дрон −груз, вакуум −ход) / топливо (+O₂) / сейф (микро-пазл)
   радар (модуль) подсвечивает 1–3 панели · РЕШЕНИЕ: эвакуироваться или ещё панель?
   состояние добычи = качество вскрытия (аккуратно → 100%, спешка → 40%)
   ↓
[СОБЫТИЕ сектора] сигнал бедствия (спасти → чертёж), элитный дереликт (охрана дронов, легенда), аномалия
   ↓
[ВОЗВРАТ] экран «Что вывезли»: сортировка трофеев — ПРОДАТЬ / ВСТРОИТЬ В КОРАБЛЬ / НА ВИТРИНУ
   (здесь interstitial — неигровой экран, compliant п.4.4)
   ↓
[КОРАБЛЬ] апгрейд: модули в отсеки, уровень корпуса, лицензии секторов → новый вылет
```

**Ежедневные крючки:** сигнал дня + лидерборд «стоимость вывоза», стрик-топливо (7 дней → бесплатный премиум-сектор), ротация модификаторов секторов по неделям.

### 1.3. Механика вскрытия: B — ядро, C — экспериментальный слой (ваше решение №1)

**B «Сетка отсеков» (ядро, в MVP):** push-your-luck на сетке; скилл = чтение риска (паттерны hazard'ов учатся: радиация тяготеет к реакторному отсеку, груз — к трюму) + тайминг эвакуации. Детерминированно, телеметрично, работает на тачскрине и мышью, 45+ понятно («морской бой»-грамотность аудитории).
**C «Физическая резка» (спайк 5 дней, gated):** Matter.js/poly-decomp, рез корпуса по линии свайпом, куски разлетаются, внутри видна начинка. **Критерии гейта:** (1) «вау» на 5 независимых зрителях; (2) ≥45 FPS на среднем Android при 40+ осколках; (3) управляемая детерминированность (содержимое не зависит от физики). **Если прошёл** — C становится режимом вскрытия ЭЛИТНЫХ дереликтов (премиум-контент: «ручная резка» за повышенный лут + отдельная RV-точка «кислород для резки»), B остаётся массовым. **Если не прошёл** — C закрывается без сожалений, B самодостаточна. Так вы получаете шанс на «ту самую» зрелищность, не ставя на неё проект.

### 1.4. Предметы: тройное назначение (ответ на ваш вопрос «зачем коллекционировать»)

| Редкость | Примеры | Судьбы (выбор игрока) |
|---|---|---|
| Хлам | обломки обшивки, кабель | переплав → **материалы корпуса** (строительство) |
| Обычные | уцелевшие блоки, инструмент | продать / **встроить** (модуль с эффектом) |
| Редкие | ксенотех, навигация | продать дорого / **компонент чертежа** |
| Эпические | реакторные кольца, ИИ-ядра | **супер-модуль** (меняет геймплей: дрон-сборщик вскрывает 1 панель сам) / витрина |
| Легендарные | артефакты исчезнувших рас | **витрина** (доход+статус) / сет-бонус энциклопедии |

**Энциклопедия груза** (вместо альбома): сеты по фракциям (Люди/Ксено/Военные/Корпораты) → бонусы (цена продажи фракции +%, радар по фракции). **Чертежи** = целевые квесты на 3–5 вылазок («собери 3 ксенотеха + 500 материалов → модуль-телепортатор»). **Звёзды** из дубликатов (механика Лавки переносится 1:1). Каждый предмет буквально работает: греет экономику, строит корабль или кормит витрину.

### 1.5. Экономика (каркас; полная симуляция — на этапе прототипа)

Маппинг параметров Лавки v4 (провалидировано симуляцией 10K игроков):
- ящик T1/T2/T3 → дереликт сектора 1/2/3 (лут-таблицы переносятся: EV/цена 1.44/1.64/1.80);
- монеты лота → **кислород** (бюджет ходов) + топливо вылета;
- «цена ящика» → стоимость лицензии сектора + расход топлива;
- keep_refund 35% → «сдать в трюм» за 35% при нехватке места (место в трюме = апгрейд!);
- дивиденд коллекции → доход витрины при входе;
- pity 70 → гарантия чертежа за 70 панелей без эпика+.
Отличия, требующие своей симуляции: hazard'ы (отрицательные события), режим РИСК (×1.5/потеря), трюм-лимит. **Обязательство: до MVP-B прогнать economy_sim_v5 с этими механиками** (1 день работы, скрипт уже есть).

### 1.6. Монетизация (compliant, плотная)

**Rewarded (6 точек, ценность игрока → почему посмотрит):** +кислород на дереликте (сильнейшая точка жанра — «я в шаге от сейфа»); двойной груз при стыковке; радар-скан 3 панелей; аварийный возврат с грузом (при аварии); бесплатный ремонт корпуса; премиум-сигнал дня. Лимиты: кислород ≤2/дереликт, остальные 1–2/день.
**Interstitial:** стыковка после вылета (каждый раз вызываем — платформа тротлит), экран итогов сектора, запуск игры. **Sticky:** только звёздная карта/ангар (не в сетке!).
**IAP v2.0+:** отключение рекламы, скины корабля, «контракт гильдии» (косметика+удобство). Не продаём: кислород за деньги напрямую (убьёт push-your-luck), легендарки.

### 1.7. Производство и перенос из Лавки

Переносится (~60%): config-экономика, экраны решения/итога, инвентарь-энциклопедия (альбом), телеметрия+CSV, SDK-обёртка (mock→Yandex), dev-панель, пайплайн предметов (спрайт+история → карточка+описание груза), сейв-адаптер.
Новое (~40%): сетка вскрытия + кислород, звёздная карта/сектора, корабль-конструктор (модули в отсеки), режимы Прогулка/Риск, события, ИИ-напарник (тексты).
**Оценка: 7–9 недель соло до MVP-B** (против 5–7 у Лавки 2.0). Программирование 5/10 (сетка), графика 5 (стилизация), контент 6 (60–90 карточек груза + 12 шаблонов отсеков × 3 биома), backend 1, техника 4 (без физики в MVP).
**Стек:** TypeScript + Phaser 3 (сетка/спрайты/партиклы) или PixiJS; цель: <20 МБ, загрузка <4 с, 60 FPS на среднем Android.

## Часть 2. «Лавка 2.0: Аукцион — купи на глаз» — альтернатива/эволюция в той же теме

### 2.1. Почему не базовая Лавка, а аукцион

Ваши же сомнения (сложность получения = чистый RNG; коллекция «без назначения») бьют по базовой Лавке сильнее всего. Ответ — **торги**: Bid Wars 2 (аукционы складов/антиквариата) — **10M+ загрузок, 4.5★, 1.52M отзывов** (Google Play, 09.2026 — факт); франшиза живёт с 2015 (Bid Wars 1+2) → тема «торгов на глаз» доказана именно на взрослой казуальной аудитории [факт+наблюдение]. На Яндекс Играх аукционных игр в топах нет [наблюдение по каталогу] → белое пятно при доказанном внешнем спросе. Это сильнейшая комбинация «доказанный спрос + пустая полка» во всём портфеле.

### 2.2. Core loop v2

```
[УТРО ЛАВКИ] дивиденд коллекции + бесплатный «лот-сюрприз» дня (стрик)
   ↓
[АУКЦИОН] 5–7 лотов и 2–4 ИИ-соперника с характерами:
   Барон (перебивает на милитарии), Антиква (холодно торгуется за редкое),
   Бабуля (непредсказуема, сбивает цену), Коллекционер (охотится за сетами)
   ОЦЕНКА ПО УЛИКАМ (скилл!): клеймо на ящике, вес, эпоха, силуэт, «слухи» —
   игрок прикидывает стоимость ДО торгов; «Глаз оценщика» (апгрейд/RV) уточняет
   ↓
[ТОРГИ] раунд 15–20 сек: поднять ставку / спасовать; бюджет ограничен;
   блеф-механика: соперники «дышат» (анимация ставки) — можно выдавить их на переплату
   ↓
[ВСКРЫТИЕ] выигранный лот открывается: анимация, находка (та же таблица редкостей v4)
   ↓
[РЕСТАВРАЦИЯ] те же мини-игры (очистка/сборка/полировка) → качество → цена
   ↓
[ОЦЕНКА+ИСТОРИЯ] → [ПРОДАТЬ / ОСТАВИТЬ] (сет-бонусы, звёзды, дивиденд — всё из v4)
   ↓
[ЛАВКА] апгрейды, витрина, подготовка к завтрашнему аукциону (interstitial на переходе)
```

### 2.3. Как это закрывает ВСЕ скрытые проблемы (ваш запрос)

| Проблема | Решение в 2.0 |
|---|---|
| Добыча = чистый RNG, нет скилла | **Оценка по уликам + торги** = знание и психология; «я переиграл Барона» — чувство компетентности |
| Предметы «ни для чего» | сеты (+8/16%), дивиденд, звёзды, **заказы коллекционеров** (v1.1: NPC ищет конкретный предмет, платит ×2–3) |
| Сходство с кейс-симами / Аномальной барахолкой | торги с характерами — механика, которой на платформе нет [наблюдение] |
| Азартный флёр (модерация) | аукцион = скилл-механика; лексика «торги/лот/оценка»; 6+ |
| Слабое первое впечатление | сцена торгов с соперниками визуально богаче одиночного ящика; скриншот «я перебил ставку и забрал сейф» продаёт игру |
| Дети (бонус-аудитория) | персонажи-соперники мультяшны и смешны (Бабуля-перекупщица!); вскрытие лота = universal fun; 6+ |
| Контент-конвейер | тот же пайплайн предметов + 5–7 портретов соперников (разово) + «гастроли аукционов» (темы торгов: военный, дачный, космический…) |

### 2.4. Кросс-демографичность (ваш вопрос «м+ж 45+ и дети»)

- Женщины 45+: реставрация/коллекция/истории/уют лавки (cozy-слой) + «Бабуля»-персонаж.
- Мужчины 45+: торги/оценка/«купи-продай» (Авито-грамотность), военный/техно-лут.
- 25–44: ресейл-фэнтези (Мой Ресейл доказал волну — факт).
- Дети 9+: персонажи + открытие лотов; без чтения сложных текстов играбельно (иконки улик).
Это первая концепция портфеля с честным покрытием всех четырёх сегментов.

### 2.5. Производство

База: **MVP-A Лавки уже построен** (эконом-тесты 17/17, смоук 23/23). Добавляется: модуль торгов (ИИ-характеры = конечные автоматы ставок: ~1 неделя), экран аукциона, улики (данные в items.json: `clues: ['клеймо','тяжёлый','эпоха 50-х']`), 5 портретов. Оценка MVP-B: **5–7 недель**.
Оценка по матрице: аудитория 8, впечатление 8, удержание 8, прогресс 8, монетизация 9, реиграбельность 8, расширение 8, лёгкость 7, риск 6, конкуренция 6, дифференциация 9, MVP 8 → **7.82 — максимум портфеля**.

### 2.6. Альтернативы в той же теме (если торги не пойдут)

1. **«Мастерская реставратора»** (V3, 7.54): сервисная рамка, клиенты несут предметы; самый низкий модерационный риск; слабее крючок.
2. **«Дедов чердак / Коп»** (metal detecting): культурно сильная тема для м 40+ (коп-сообщества огромны [наблюдение]), но игровая валидация слабая: Treasure Hunter Metal Detector — всего **10K+ загрузок** (Google Play, 08.2026 — факт); Retro Relics — свежий инди без подтверждённых цифр. Брать только как рескин-опцию после валидации ядра.
3. **«Гараж №42»** (V2, 7.53): мужской ностальгический, но полка частично занята («Ретро Гараж» 72/100 — факт) и женская половина теряется.

### 3.2. Рекомендуемый план (последовательный портфель на общем движке)

**Недели 1–2 — два спайка параллельно (дешёвые гейты):**
- Спайк А (2–3 дня): модуль торгов для MVP-A Лавки (один аукцион, 2 ИИ-характера, улики) → плейтест-панель 35–60 (8–12 чел.) сразу на версии 2.0: проверяем «торги добавляют или пугают».
- Спайк Б (5 дней): сетка вскрытия Космо-лома (один дереликт, кислород, эвакуация; плейсхолдеры) → само-тест 10 забегов + 5–8 плейтестеров 18–40 → гейт «20 минут фана». Опция: 2 дня на C-спайк (физрезка) после B — по критериям 1.3.
**Недели 3–7 — первый релиз:** тот из спайков, что прошёл гейт лучше, уходит в MVP-B. При обоих PASS — **Лавка 2.0 первая** (на 2–3 недели ближе к деньгам, RU-ядро = высокий CPM, код готов на 80%).
**Недели 8–15 — второй релиз:** Космо-лом v2 (мультипортально; к этому моменту у вас есть опыт платформы, первые деньги, отзывы, A/B-навык).
**Месяцы 4–6:** live-ops обоих (контент-конвейер 15–30 карточек/мес на игру), IAP на лучшей, заявка в «Популярные», платное продвижение при ROI.
**Матожидание цели:** две игры × 1–2 тыс. ₽/день к 4–6 месяцу = ваши 3–4 тыс. ₽/день; одна из них может выстрелить выше (асимметрия в вашу пользу). Гарантий нет — есть гейты, режущие потери, и портфель, снижающий дисперсию.

### 3.3. Если выбирать ОДНУ игру (ваш сценарий «только Космо-лом»)

Жизнеспособно: 7.72 против 7.82 — разница в пределах шума; ваша мотивация — реальный фактор соло-разработки (вероятность дойти до конца). Цена выбора: +2–3 недели до первого дохода и повышенный платформенный риск (sci-fi на Яндексе). Компенсация: мультипортальность обязательна с дня 0. **Условие: сначала гейт сетки (спайк Б) — без «20 минут фана» проект не начинаем, какие бы симпатии ни были.**

### 3.4. Kill criteria (напоминаю, чтобы зафиксировать до старта)

- Спайк А: торги «пугают/скучны» у ≥60% панели 45+ → Лавка остаётся базовой (без торгов) или → Мастерская (V3).
- Спайк Б: сетка не даёт «ещё один дереликт» у ≥50% панели → Космо-лом откладывается; ресурсы в Лавку 2.0.
- Gate 2 (платформа, 7–14 день): D1 <10% после фикса FTUE/иконки → рескин темы при живых системах (движок-то общий!).
