## 1. Бизнес-контекст и целевая функция заказчика

- **Цель:** сделать игру (портфель игр) для публикации в **Яндекс Играх** с монетизацией через Яндекс Игры SDK (реклама; позже IAP) и выйти на **~3–4 тыс. ₽/день** регулярного дохода «быстро и без непреодолимых сложностей».
- **Ресурсы:** соло-разработчик + ИИ-помощь. Бюджета на UA и арт-аутсорс нет. Движок/стек: веб (HTML5), без backend.
- **Личные предпочтения заказчика:** нравится sci-fi (его ранние идеи: пиксельный слешер-рогалик про космического наёмника; 3D CTF роботы-vs-жуки). После анализа sci-fi-слэшер отложен (см. §4), заказчик выбрал ветку «Лавки» и активно участвует в её дизайне (его ключевой вклад — требование «предметы должны иметь назначение, а не просто коллекционироваться»).
- **Математика цели (честно):** средний eCPM Яндекс Игр ≈ **20 ₽/1000 показов** (отчёт разработчицы, DTF, 10.2024, https://dtf.ru/indie/3063739); при плотной rewarded-модели (4–6 показов/DAU) цель 3–4 тыс. ₽/день ≈ **15–25 тыс. DAU** — уровень уверенного середняка-плюс платформы, НЕ медиана (медиана: десятки тысяч ₽/мес — заявление VK, App2Top 28.08.2025). Реалистичный горизонт: 3–6 месяцев; надёжнее портфель из 2 игр × 1,5–2 тыс. ₽/день. Гарантий нет; управление рисками — через гейты (§8).

## 2. Ключевые факты о платформе (выжимка исследования)

Полные источники — `issledovanie-rynka-yandex-games.md`. Главное:
- **Аудитория:** 40+ млн MAU (2024); 58% женщины; 38% — 55+; 60% Россия / 40% мир; 45+ — самая дорогая по CPM (заявление Яндекса, App2Top 28.08.2025). Дети официально 9% (вероятно недоучтены).
- **Трафик:** ML-ранжирование по возвращаемости/сессиям/доходу; раздел «Новые» даёт <30% трафика; системе рекомендаций хватает ~1 недели на вердикт; «красные» игры (слабые ARPU/время) трафик теряют (документация: https://yandex.ru/dev/games/doc/ru/concepts/ranking-and-featuring).
- **Реклама (правила п. 4.4):** rewarded без ограничений частоты, но награда = дополнительный бонус, не гейт (п. 4.5.2); interstitial только в логических паузах после неигровых действий (задержка ≤2 с), частотой управляет платформа; в реальном времени при уровнях <5 мин реклама в процессе запрещена; sticky только на неигровых экранах; пауза звука/геймплея при показе (п. 4.7); `gameplayAPI.stop()/start()` вокруг показов;игру запрещают дёргать рекламу по setInterval — показы инициирует платформа (антифрод-контроль, п. 4.4.2).
- **Техника:** ZIP ≤100 МБ, index.html в корне; облачные сохранения ≤200 КБ/игрок (≤100 запросов/5 мин); лидерборды, IAP с серверной валидацией, A/B иконок, автоопределение языка (п. 2.14), гостевой режим обязателен (п. 1.2.2), прогресс не должен теряться при повороте/рефреше (п. 1.9), интерактивный ИИ запрещён, предгенерированный ИИ-арт разрешён (п. 1.23).
- **Модерация:** 3–5 рабочих дней; рейтинг качества ≤30 три недели → снятие (п. 2.13); запрещены: реальные деньги/лотереи (п. 3.7), религия (3.4.5), политика/войны (3.4.4), эзотерика/гадания (3.4.2), алкоголь/табак в 0+/6+; промо = ≥70% реального геймплея; дублирование своей игры запрещено (п. 3.6). Требования, ред. 18.08.2026: https://yandex.ru/dev/games/doc/ru/concepts/requirements
- **Экономика разработчика:** «хорошие гиперказуалки $10–15K/мес, казуалки $20K+, топы $70K+/мес» (Яндекс, 08.2025); кейс новичка: 1 007 ₽ за 2 недели (Habr, 2023); кейс соло-подростка: >100K ₽/мес портфелем, ~600 новинок в неделю, конкурентоспособны ~10 (DTF, 12.2024).
- **Топы каталога (game-analytics.ru, 09.2026):** кейс-симуляторы (Кейс-батл 92K оценок/год; «Мой Ресейл» 55,8K за 11 недель, релиз 07.2026), .io-арены на ботах (Бравл Старсик 3D 125K/9 мес; отзыв-жалоба «боты слишком слабые» — доказательство bot-based «мультиплеера»), merge-волна (Vista Games), классика 45+ (Море Слов 104K/6 лет), физика-краш (Смертельный Спуск 127K/2 года).
- **Жанровые табу платформы (данные):** survivors-like на Яндексе НЕ тянет: «Имбамаг Выживание» — 169 оценок за 13 мес. (Unity, загрузка 6.11 с), «Claw Master» при качестве 81/100 — ~383-е место. Экшен-спрос молодёжи уходит в .io/Roblox-подобное.
- **Внешние доказательства темы «Лавки»:** Bid Wars 2 — 10M+ загрузок, 4.5★, 1.52M отзывов (аукционы складов/антиквариат, взрослая казуальная аудитория); Hardspace Shipbreaker 500K+ (тема разборки кораблей для «Космо-лома»); Unpacking 1M+/год (cozy-раскладка).

## 3. Дизайн-эволюция и текущая концепция «Лавка 2.0: Аукцион»

**Цепочка решений:** 13 концепций → матричное сравнение → победа «Лавки древностей» (box opening + реставрация + коллекция; 8.0) → red-team валидация (симуляция экономики 10K виртуальных игроков выявила 3 ошибки: сжигание денег коллекционированием, исчерпание каталога к d25–30, слишком ранний pity) → экономика v4 (комиссия коллекционера 35%, каталог 90, pity 70 как страховка хвоста, дивиденд коллекции) → заказчик поставил вопрос «зачем коллекционировать без назначения» → **эволюция в «Лавку 2.0: Аукцион»** (торги с NPC + заказы + функциональные сеты; оценка по матрице 7.82 — максимум портфеля; Bid Wars как доказательство механики).

**Ядро 2.0 — три столпа ценности (не больше, по принципу «удалили фичи — retention вырос»):**
1. **Арбитраж:** улики (категория-на-глаз, эпоха, материал, вес, маркировка, слова продавца, состояние упаковки, частичное фото на усадебном/гаражном аукционах) сужают диапазон оценки ×2.6→×1.38; скрытое состояние 0.7–1.3; ставка ниже стоимости = маржа. Точная полоса оценки платит +25 ₽.
2. **Заказы:** 18 шаблонов клиентов (конкретный предмет ×3.0 / категория ×2.2 / редкость ×2.5), дедлайны, вкусовые хвосты фраз; бейдж «📋 заказ» на лоте ДО торгов — главный генератор «хочу ИМЕННО этот лот».
3. **Сеты + лавка:** 3 набора (Советская электроника → заказы техники ×1.5; Мастер и приборы → оценка точнее 25%; Уютный дом → +15% продаж категории), 4 фикстуры (радиола +5% продаж, ходики +1 день заказов, швейная машина +15% к полу качества, часы — улики точнее), витрина легенд (+8%), 3 уровня лавки (Ларёк → Антикварная лавка → Мастерская древностей) с реальными открытиями (аукционные дома, слоты заказов, витрина, доп. улика) и альт-гейтом «наборы ИЛИ N заказов».

**Цикл дня (4–7 мин):** утро (дивиденд, доска заказов, цель накопления) → выбор аукциона (Городской склад / Усадебный / Гараж мастеров — разные пулы, старт-цены, улики; усадебный и гараж дают частичное фото) → осмотр 4–6 лотов (5 типов упаковок: коробка/чемодан/мешок/обрешечённый ящик/кофр — влияют на улики и разброс состояния) → торги за каждый лот → выигрыш: вскрытие → реставрация (3 мини-игры: очистка/полировка/сборка черепков; для хлама ≤30₽ — быстрый режим «обтереть») → оценка (база×состояние×качество) → решение (заказ/продать/в коллекцию/фикстура/витрина; дубликат — автопродажа 40%) → проигрыш: обучающий экран (победитель, цена, истина, «вы остановились на X», подсказка архетипа) → итоги дня (прибыль, точность оценок) → новый день.

**NPC (конечные автоматы, шум кэпов ±15%):** Аркадий-Коллекционер (×1.5–1.8 на технике/часах, ♥-tell), Зинаида-Перекупщица (×0.68–0.85, рано пасует), Пётр-Часовщик (только часы/приборы ×1.15–1.35, на прочее мгновенный пас), Бабуля Нина (×0.4–1.4, переплачивает за хлам — рыночный шум). Игрок учится их паттернам через экраны проигрыша.

**Экономика (параметры v4, калиброваны симуляцией; источник истины — CONFIG в `lavka2-vp/js/data.js`):** старт 600 (в 2.0) / 450 (симуляция Лавки v1); лот T1 ~150±12%; EV/цена ≈ 1.44–1.80 по ярусам (положительное EV — азарт без риска потери); качество реставрации q∈[0.35;1] → множитель 0.6+0.6q; «оставить» = 35% цены; дубликат = 40%; сеты +8/+16%; дивиденд входа 30+25×сеты; pity 70 (в 2.0 не активирован — нет «ящиков» в чистом виде, переносится в MVP-B для спец-лотов).

**Монетизация (mock в прототипе):** rewarded — премиум-лот дня, авто-реставрация (×3/день, «пропуск уровня» — разрешённый пример в документации), удвоение продажи, доп. улика (×2), отмена продажи; interstitial — утро→аукцион (каждый 2-й день), итоги дня; sticky — только хабы. IAP — НЕ в MVP (обязательства п. 1.13 + непроверенный спрос); план v2.0: отключение рекламы, косметика. Антипаттерн-контроль: базовый цикл играбелен без рекламы вечно (bailout +150 при <120 — телеметрируется).

**Модерационный чек-лист (соблюдён в каталоге):** нет религии/политики/войн/эзотерики/алкоголя/табака/оружия/реальных брендов; лексика «лот/аукцион/находка» (не «ставка/джекпот/казино»); цель — рейтинг 6+; только внутриигровая валюта.

**FTUE (день 1, скриптован):** заказ Иваныча (ретротехника ×2.2) до первого аукциона → 4 лота (телефон, кассетный плеер, значки, крынка) с заниженными кэпами NPC → первый выигрыш → авто-реставрация → «Отдать Иванычу за ~213 ₽» → урок замкнут. Подсказка на первых торгах: «У соперников свой предел цены…».

## 5. Техническое состояние (что построено и проверено)

### 5.1 `lavka-vp/` — MVP-A «Лавки древностей» (первая версия, box opening)
Полный цикл: лот → вскрытие → реставрация (canvas-очистка) → оценка/история → продать/оставить → альбом. 19 предметов (SVG+истории), экономика v4 в config, MockSDK, телеметрия+CSV, ?gate0/?dev=1. Тесты: 17/17 экономика, smoke 23/23. **Роль:** донор кода и резервный вариант «чистого box-opening» (ветвление §8).

### 5.2 `lavka2-vp/` — «Лавка 2.0: Аукцион» (текущий основной прототип)
- **Запуск:** открыть `index.html` (file://, ноль зависимостей); `?dev=1` — панель метрик (включая IMS) + CSV; `?speed=fast` — быстрые торги.
- **Модули:** `data.js` (CONFIG, 35 предметов, 3 сета, 4 фикстуры, 4 NPC, 18 заказов, 3 аукционных дома, 5 упаковок, FTUE), `economy.js` (оценка/кэпы/цены/выплаты), `systems.js` (AuctionSystem, NPCBidderSystem, ClueSystem, OrdersSystem, GoalsSystem, PostAuctionResultSystem + алиасы LotValuationSystem/CollectionGoalSystem), `restore.js` (3 мини-игры + быстрый режим хлама), `game.js` (сцены дня, async-движок торгов), `sdk.js` (MockSDK — сигнатуры совпадают с будущим YandexSDK), `telemetry.js`, `sfx.js` (WebAudio-синтез), `main.js`.
- **Телеметрия:** все 14 событий спецификации заказчика (auction_started, lot_inspected, clue_opened, bid_started, bid_raised, bid_stopped, auction_won, auction_lost, item_revealed, item_restored, item_sold, item_kept, goal_completed, next_auction_started) + estimate_submitted/resolved(diff), npc_pass, decision(motivation), day_end, dividend, bailout, ftue_step, ad_* — CSV-экспорт.
- **Метрики dev-панели:** ставки/аукцион, ср. макс. ставка, winRate, ср. маржа, точность оценок + ср. |ошибка|, доля мгновенных продаж, пауза день→аукцион, аукционов/сессию, **Item Motivation Score** (order/set/improvement/resale/collection/other; красная линия <50%).
- **Тесты:** `tests/logic_tests.js` — 37/37 (node, без зависимостей); `tests/smoke_game.js` — полный FTUE-день headless (jsdom, ~30 проверок) PASSED; `tests/selftest.js` — бот играет 3 дня, отчёт в `tests/selftest_report.json`.
- **Самотест бота (3 дня):** 4 победы / 12 честных поражений (политика «бьюсь только за мотивированные»), 100% положительных маржей, IMS 100% (3 заказа + 1 перепродажа), все системы стабильны. Ограничение: бот идеален в оценках и всегда берёт авто-реставрацию → его доходы — верхняя граница; «фан» бот не измеряет.
- **Известные ограничения:** плейсхолдерный SVG-арт (стиль не финализирован — ждёт A/B); только RU; localStorage (облако — в MVP-B); реклама — mock; баланс NPC/маржи — первый проход; портретная вёрстка торгов на реальном телефоне не проверена (CSS-митигция добавлена: горизонтальный скролл NPC <430px).

3. Live-ops план: контент-конвейер 15–30 карточек/мес.; v1.1 — торги-«гастроли», четвёртая эпоха, страховка лота; v1.2 — музей-витрина с доходом входа; v2.0 — IAP.

## 8. Гейты и ветвления (правила принятия решений — НЕ нарушать)

**Gate 1 — Core Fun:** игрок без объяснений понимает «я выбираю, за что бороться»; решения осознаннее после 2–3 аукционов (рост точности оценок у ≥60% панели).
**Gate 2 — Motivation:** ≥60% побед мотивированы (IMS), игрок формулирует конкретную цель до аукциона; «хочу посмотреть, что выпадет» — НЕ зачёт.
**Gate 3 — Replay:** ≥50–60% добровольно начинают ещё цикл; ≥30–40% играют >15 мин; большинство объясняет назначение типов предметов. (Пороги — эвристики прототипа, не рыночные KPI.)

**Ветвления (договорённость с заказчиком — не защищать концепцию):**
| Исход | Действие |
|---|---|
| Торги интересны, предметы бессмысленны (IMS<50%) | пересобрать систему ценности (заказы в ядро, сеты → функциональные награды) |
| Предметы ок, торги мешают | упрощение аукциона (быстрая ставка в один тап, авкоторги за долю маржи) |
| Оба ок | Лавка 2.0 → MVP-B |
| Нравится только открытие лотов | откат к box-opening (код `lavka-vp` жив) или «Барахолка» |
| Реставрация — самая сильная часть | pivот «Мастерская реставратора» |
| Gate 3 провален дважды | без косметики — возврат к портфельной развилке (Словарь/Бастион/Космо-лом) |

**Kill-правила платформы:** рейтинг качества ≤30 три недели → снятие; D1 <10% после фикса FTUE/иконки → рескин темы при живых системах; бюджет-kill: MVP-B >8 недель → резать скоуп.
