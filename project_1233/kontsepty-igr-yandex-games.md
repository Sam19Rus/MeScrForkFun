# Концепции игр для Яндекс Игр — на основе исследования рынка

**Дата:** 21.09.2026. Основание: см. файл `issledovanie-rynka-yandex-games.md` (далее — Отчёт).
Оценки 1–10 — **инструмент сравнения**, а не прогноз результата. Шкала сложности: 1 = тривиально, 10 = уровень студии.

**Общий принцип отбора концепций:** простое управление + понятная за секунды механика + глубокая мета-прогрессия + высокий replayability + совместимость с рекламными правилами Яндекса (пошаговость/раунды) + реализуемость соло за 4–10 недель до MVP.

---

## Концепт №1. «Лавка древностей: Тайные ящики»

**Hook:** Психология кейс-симов (главный хит-кластер Яндекса), но для взрослой аудитории: вы скупаете тайные ящики на аукционах, реставрируете находки мини-играми и собираете музей редкостей — «Кейс-батл» для тех, кто вырос из Стандоффа.

**Gameplay loop:** выбрать лот на аукционе (ставка монетами) → открыть ящик (случайная находка: от хлама до раритета) → реставрировать (мини-игра 30–60 с: оттереть грязь, собрать черепки, отполировать) → оценить предмет → продать (деньги) ИЛИ оставить в коллекцию (альбом) → деньги → более дорогие аукционы, улучшение лавки, инструменты реставратора → новые ящики и эпохи.

**Почему будут возвращаться:** (1) переменная награда — главный доказанный драйвер платформы (Отчёт, кластер A); (2) альбом коллекционера с сетами по эпохам (СССР-быт, имперская Россия, ретро-техника, «90-е») — долгая цель; (3) ежедневный бесплатный лот и «аукцион дня» с лидербордом; (4) музей-витрина: оставленные предметы генерируют пассивный доход посетителей (idle-бонус, но не ядро); (5) истории предметов («находка с историей» — 2–3 предложения текста, дешёвый нарратив); (6) редкие «легендарные» находки как долгосрочная охота.

**Почему подходит Яндекс Играм:** спрос на box opening подтверждён 5+ играми в топах (факт, Отчёт 2.1); аудитория 35–60 (≈54% платформы по данным промо-страницы) тематически не обслужена — все конкуренты про молодёжные скины; пошаговый формат = легальные точки interstitial по п. 4.4; UI-driven = лёгкая сборка, быстрая загрузка (важно для метрик); тема «кладовки/дачи/блошиного рынка» культурно близка RU-аудитории **[гипотеза]**.

**Монетизация:** rewarded — бесплатный ежедневный ящик, «переоткрыть» ящик, ускорение реставрации, «глаз оценщика» (подсказка редкости до покупки лота), страховка от хлама; interstitial — после завершения реставрации/возврата на аукцион (неигровое действие, соответствует требованиям); sticky-баннер в лавке; позже IAP — отключение рекламы, премиум-аукционы, косметика витрины.

**MVP (4–6 недель):** один аукцион, ~60 предметов (4 редкости), 2 мини-игры реставрации, альбом на 40 слотов, продажа/коллекция, 3 апгрейда лавки, облачные сохранения, лидерборд «состояние», RU+EN.

**Развитие:** 1.1 — третья мини-игра + «заказы коллекционеров» (целевой поиск предмета — добавляет планирование); 1.2 — музей с экспозициями и idle-доходом, ежедневные квесты; 2.0 — эпохи-кампании с сюжетом, «аукционные дуэли» с призраками других игроков (асинхронный PvP без сервера), сезонные события.

**Сложность:** программирование 4; графика 5 (иллюстрации предметов — основная статья; единый стиль, частично ИИ-арт допустим с 05.2026); контент 6 (каталог предметов растёт бесконечно, data-driven); backend 1 (не нужен); техника 3; **объём работ 5/10**.

**Риски:** тема может не «зайти» молодёжи, делающей кассу кейс-симу (митигация: игра целится в другой сегмент); стоимость арта предметов (митигация: стилизация, партии по 10–15 предметов за итерацию); ассоциация с азартными играми — нужно пройти модерацию с рейтингом 6+/12+ и без намёка на реальные деньги; конкуренция за внимание внутри кластера.

**Потенциал:** привлечение 8 (доказанный триггер + свежая тема); удержание 8; монетизация 9 (box opening = максимальная плотность rewarded-точек); простота разработки 7; масштабируемость 8 (предметы/эпохи/музеи).

## Концепт №2. «Зельеварня» (merge-менеджмент лавки)

**Hook:** Уютный merge-магазин: выращивайте ингредиенты, сливайте их на доске, варите зелья для причудливых клиентов и открывайте рецепты — Monkey Mart встречает merge-тренд Яндекса.

**Loop:** клиент с заказом → собрать цепочку ингредиентов на merge-доске (слияние 1+1=2→…) → сварить зелье → отдать → монеты + репутация → апгрейд лавки/новые грядки/слоты рецептов → более сложные заказы и редкие клиенты.

**Возвраты:** книга рецептов (открытия), рост лавки (видимый прогресс), редкие клиенты с микро-историями, ежедневный «особый заказ», энергия грядок (мягкий возвратный таймер), сезонные события.

**Почему ЯИ:** merge — самая быстрорастущая casual-волна платформы (Сквиши Мерж/Верити Мерж в топ-3 роста, факт); женская аудитория 58%; пошаговость = compliant-реклама; idle-менеджмент доказан в вебе (Monkey Mart — топ Poki).

**Монетизация:** rewarded — энергия, удвоение выручки с клиента, вызов редкого клиента, мгновенная варка; interstitial — между циклами обслуживания и при открытии лавки/книги; IAP — отключение рекламы, декор.

**MVP (4–6 недель):** доска 6×8, ~30 предметов в 6 цепочках, 8 зелий, очередь клиентов, 5 уровней апгрейда, сохранения, RU+EN.

**Развитие:** 1.1 — заказы коллекционеров и книга рецептов с бонусами сетов; 1.2 — огород (idle-выращивание), коллекция зелий-трофеев; 2.0 — нарративная кампания (история лавки), события, второй этаж с новыми механиками (зачарование).

**Сложность:** программирование 5; графика 5; контент 6; backend 1; техника 3; **объём 5/10**.

**Риски:** высокая конкуренция в merge (Vista Games и др. с отлаженным пайплайном); без нарратива удержание ниже, чем у мидкор-лидеров; раздражающий баланс энергии; «ещё одна merge-игра» может не выделиться в рекомендациях.

**Потенциал:** привлечение 7; удержание 8; монетизация 8; простота 7; масштабируемость 8.

## Концепт №3. «Цех» (фабрика-конвейер: головоломки оптимизации)

**Hook:** Карманная фабрика: стройте конвейерные линии на сетке, чтобы цех выполнил план — компактные головоломки оптимизации + бесконечная песочница + лидерборд эффективности. Factorio/Shapez за 5 минут, без сложности входа.

**Loop:** получить план (выпустить N деталей за T секунд) → расставить машины и конвейеры на сетке → запустить → наблюдать поток, найти узкое место → перестроить → план выполнен → звёзды/чертежи → новые машины (разветвители, красильни, прессы) → более хитрые планы.

**Возвраты:** лидерборд эффективности по каждому уровню (себестоимость/скорость) — «переиграть себя и других»; песочница со своими вызовами; открытия новых машин (каждая меняет стратегию); «план дня» (ежедневный сид для всех игроков); медитативность процесса (наблюдение за потоком — доказанный кайф жанра).

**Почему ЯИ:** десктоп-сегмент 25–44 частично не обслужен «умными» играми (ниша пуста в топах — Отчёт, синтез); головоломки — ядро платформы; пошаговость = реклама после выполнения плана; лёгкая 2D-сборка; вирусный потенциал скриншотов «идеальной фабрики» **[домысел]**.

**Монетизация:** rewarded — подсказка, дополнительный чертёж, удвоение награды, «турбо-режим» на 1 запуск; interstitial — после выполнения/провала плана; IAP — отключение рекламы, паки уровней-кампаний.

**MVP (6–8 недель):** сетка 12×12, 6 типов машин, 30 уровней кампании + бесконечный режим с ежедневным сидом, лидерборды SDK, RU+EN.

**Развитие:** 1.1 — логические машины (красители, сортировщики), кампании по отраслям (пекарня, автозавод); 1.2 — шеринг фабрик строкой-кодом (дешёвая «социальность»), галерея чужих решений; 2.0 — турниры «фабрика недели», изометрический визуал, многоэтажные цеха.

**Сложность:** программирование 7 (симуляция потоков, но без физики); графика 4 (функциональный стиль); контент 5 (левел-дизайн — ручной труд); backend 1; техника 5; **объём 6/10**.

**Риски:** ниша уже, чем массовые жанры (не для женщин 55+); балансировка уровней требует вкуса; низкий вирусный потенциал у детей; лидерборд эффективности может демотивировать казуалов (митигация: отдельный «спокойный» режим без лимитов).

**Потенциал:** привлечение 6; удержание 9 (оптимизация — одна из самых «залипательных» петель); монетизация 7; простота 6; масштабируемость 7.

## Концепт №4. «Бастион» (merge + tower defense)

**Hook:** Слияние пушек прямо на крепостной стене: короткие забеги по 3–5 минут, где решения «что смержить и куда поставить» решают исход волн — два самых горячих жанра платформы в одном.

**Loop:** волна врагов → на доске сливать одинаковые пушки в более сильные → расставлять на стене → отбить волну → ресурсы → между волнами: апгрейды/расширение доски → глубокие волны → смерть/победа → мета-валюта → открытия новых веток пушек → новый забег.

**Возвраты:** древо технологий и новые пушки (билд-разнообразие), ежедневный забег-челлендж с фиксированным сидом, лидерборд «максимальная волна», сезоны/лиги **[гипотеза по мобильным аналогам]**.

**Почему ЯИ:** TD стабильно присутствует в каталоге, merge растёт (факт), а гибрида почти нет (наблюдение); забеговая структура = идеальные легальные точки interstitial; rewarded-revive — жанровый стандарт.

**Монетизация:** rewarded — воскрешение, стартовый буст, удвоение награды за забег, бесплатная волна-передышка; interstitial — после забега; IAP позже.

**MVP (6–8 недель):** 1 карта, 5 типов пушек × 3 уровня слияния, забеги на 15 волн, 10 мета-апгрейдов, лидерборд, RU+EN.

**Развитие:** 1.1 — +2 карты, боссы, стихии; 1.2 — ежедневные челленджи, новые ветки, модификаторы забегов; 2.0 — герои с умениями, события, сезоны.

**Сложность:** программирование 7 (волны, pathing, баланс); графика 6; контент 5; backend 1; техника 5; **объём 6/10**.

**Риски:** баланс merge-экономики против TD-сложности — классическая ловушка жанра; на мобайле гибриды сильные (конкуренция при портировании издателями на веб); средняя для соло длительность разработки.

**Потенциал:** привлечение 7; удержание 8; монетизация 9 (revive/бусты — органика жанра); простота 6; масштабируемость 7.

## Концепт №5. «Глубина» (рыбалка-экспедиция: коллекция + спокойная прогрессия)

**Hook:** Спокойная рыбалка с глубиной: каждая пойманная рыба — страница энциклопедии, каждая снасть — шаг на новую глубину, где живут легендарные существа. Коллекционерская игра с чувством «ещё один заброс».

**Loop:** заброс (тайминг-мини-игра) → вываживание → улов (обычная/редкая/легендарная) → в энциклопедию и/или на продажу → деньги → апгрейд удочки/приманок/лодки → новая зона/глубина → новые виды и погода → сбор сетов энциклопедии → бонусы.

**Возвраты:** энциклопедия с сетами (долгая коллекционная цель), «таблица клёва дня» (ежедневная вариативность), легендарные рыбы как многодневная охота, пассивные ловушки (offline-бонус), события (нерест, миграции).

**Почему ЯИ:** «симуляция + коллекция» — устойчивый растущий кластер (Больница для Животных, Закусочная 67 — факт роста); темп подходит 45+ (половина платформы); механика понятна за 3 секунды всем поколениям; раундовая структура = compliant-реклама; рыбалка культурно близка RU-аудитории **[гипотеза]**.

**Монетизация:** rewarded — удвоение улова, редкая приманка, ускорение клёва, «спасение сорвавшейся рыбы»; interstitial — между сессиями лова/при переходе между зонами; IAP — отключение рекламы, лодки/скины.

**MVP (4–6 недель):** 1 озеро, 25 видов рыб, тайминг-заброс + вываживание, 6 апгрейдов снастей, энциклопедия, облачные сохранения, RU+EN.

**Развитие:** 1.1 — море, лодка, донные ловушки (idle); 1.2 — заказы рыбаков, легендарные рыбы, погода/время суток; 2.0 — глубоководье с субмариной, аквариум-музей (витрина коллекции), сезонные миграции.

**Сложность:** программирование 5; графика 6 (арт рыб — основная статья, но каждая рыба = 1–2 спрайта); контент 6; backend 1; техника 3; **объём 5/10**.

**Риски:** рыбалки на платформе уже есть (конкуренция — наблюдение); без редкостей/сетов скучнеет за 2 дня; арт рыб должен быть узнаваемым (стиль решает).

**Потенциал:** привлечение 7; удержание 8; монетизация 8; простота 7; масштабируемость 8.

## Концепт №6. «Приют монстриков» (care + коллекция + merge-эволюция)

**Hook:** Приют для странных, но милых существ: спасайте, кормите, сливайте для эволюции и украшайте вольеры — коллекционный зоопарк без проигрыша, «приручённое Закулисье».

**Loop:** спасти существо (ежедневная бесплатная вылазка / находка) → уход (2–3 мини-действия: корм, игра, чистка) → сливать двух одинаковых → эволюция в новую форму → вольеры приносят «пожертвования посетителей» (пассивно) → расширение приюта → новые виды.

**Возвраты:** коллекция видов и цепочек эволюции (открытия), ежедневный ритуал ухода, декор приюта (самовыражение), редкие «заблудившиеся» существа, альбом достижений.

**Почему ЯИ:** care-sim растёт (Больница для Животных Онлайн — топ-7 роста, факт); merge-эволюция соединяет два рабочих тренда; «Закулисье: мерж монстров» доказал интерес к монстро-тематике (факт); детская + женская аудитория; нет fail-state = низкий стресс, длинные сессии.

**Монетизация:** rewarded — бесплатное спасение существа в день, удвоение еды, мгновенный шаг эволюции, редкий посетитель; interstitial — между циклами ухода (пошагово = compliant); IAP — декорации.

**MVP (4–6 недель):** 12 существ (4 цепочки × 3 стадии), 3 вольера, 3 действия ухода, merge-эволюция, пожертвования, RU+EN.

**Развитие:** 1.1 — посетители с заказами («показать редкое существо»), мини-игры ухода; 1.2 — ежедневные события, альбом, погода в приюте; 2.0 — экспедиции за новыми видами (короткие забеги), разведение, обмен наклейками-призраками (асинхронно).

**Сложность:** программирование 4; графика 6 (персонажный арт — ключ к успеху и главный расход); контент 6; backend 1; техника 3; **объём 5/10**.

**Риски:** без харизматичного арта игра мертва (сильная зависимость от стиля); конкуренция с детскими гигантами (FTD); «милота» должна быть оригинальной — копирование Backrooms/Brainrot-образов = IP-риск и гонка.

**Потенциал:** привлечение 7; удержание 8; монетизация 7; простота 7; масштабируемость 8.

## Концепт №7. «Ночная смена» (карточный survival-роглайт в 2 минуты)

**Hook:** Вы — смотритель удалённой заправки/маяка зимой: свайпайте решения, доживите до утра. Каждая смерть достраивает базу между забегами — Reigns встречает FTL в браузере за 2 минуты на сессию.

**Loop:** карта события (гость, поломка, погода, находка) → решение свайпом (2 варианта) → изменение ресурсов (тепло/еда/рассудок/защита) → цепочка событий ночи → утро = выжил → награда → база: новые карты в колоду, улучшения, персонажи → следующая ночь сложнее.

**Возвраты:** открытие сотен карт-событий (любопытство — «что будет, если…» — сильнейший драйвер жанра), мета-база (постоянный прогресс сквозь смерти), несколько концовок, персонажи-помощники, «ещё одна ночь» после обидной смерти.

**Почему ЯИ:** сессия 1–3 минуты = идеальный веб-формат и идеальная точка interstitial (после ночи — неигровой экран); нарратив удерживает взрослую аудиторию 35+, которой не хватает «историй» вне мидкора (наблюдение); графика минимальна — главный актив текст; в топах Яндекса аналогов нет (пустая ниша — факт по каталогу).

**Монетизация:** rewarded — «второй шанс» (отменить смерть), удвоение утренней награды, бесплатный пак из 5 новых карт; interstitial — между ночами; IAP — сюжетные кампании-DLC (естественная модель жанра).

**MVP (5–7 недель):** 80–100 карт-событий, 4 ресурса, 1 локация, 10 улучшений базы, 2 концовки, RU+EN (текст! — главный объём работ).

**Развитие:** 1.1 — новые персонажи-помощники и ветки событий; 1.2 — коллекция находок (артефакты с историями), 4 концовки; 2.0 — вторая локация (зимовье/маяк), сезонные события, режим «длинной недели».

**Сложность:** программирование 4; графика 3 (карточный стиль, 20–30 иллюстраций); контент 7 (качественный текст — основной расход и риск); backend 1; техника 2; **объём 5/10**.

## Концепт №8. «Словарь забытых слов» (word-craft + фабрика + ежедневность)

**Hook:** Не кроссворд, а фабрика слов: собирайте слова из букв-деталей на конвейере, выполняйте планы, открывайте редкие и устаревшие слова и коллекционируйте «словарь» с их историями — словесная игра для платформы, где «Море Слов» живёт 6-й год.

**Loop:** план (собрать слова на тему/из корней) → перетаскивать буквы на конвейер-слоты → слово собрано → очки/новые буквы-редкости → открытие слова в словаре (значение + 1–2 предложения истории) → апгрейд «цеха грамотности» → более сложные планы (цепочки слов, ограничения).

**Возвраты:** «план дня» для всех игроков + лидерборд (ежедневность — доказанный драйвер 6-летних хитов), словарь-коллекция (сотни слов с историями — edutainment для 45+), стрики, тематические цеха (кухня, космос, море).

**Почему ЯИ:** словесные игры — доказанный долгожитель платформы (факт: Море Слов 104,6 тыс. оценок за 6 лет); аудитория 45+ (38%) — ядро; пошаговость = compliant-реклама; контент генерируется из словарной базы (дешёвая масштабируемость); дифференциация от сотен кроссвордов — «фабрика + коллекция знаний».

**Монетизация:** rewarded — подсказка, «подвоз букв», удвоение очков плана, пропуск ошибки; interstitial — между планами; sticky в меню; IAP — отключение рекламы.

**MVP (4–6 недель):** ядро сборки слов, словарь на 200 слов (готовые открытые списки + редактура), план дня, лидерборд, 5 апгрейдов, RU (EN-версия — отдельная словарная база позже).

**Развитие:** 1.1 — тематические цеха и комбо-цепочки; 1.2 — дуэли с призраками (асинхрон), турниры выходного дня; 2.0 — «город слов» (кампания по районам), события к праздникам, своя версия для EN-рынка.

**Сложность:** программирование 5; графика 4; контент 4 (словарь + короткие тексты; генерация планов); backend 1; техника 3; **объём 4/10** — одна из самых дешёвых концепций.

**Риски:** гиганты словесного жанра занимают полку (конкуренция за «ту же» аудиторию); фабричный слой может показаться шумом консервативным игрокам (митигация: режим «классика»); качество русского словаря и валидация слов.

**Потенциал:** привлечение 7; удержание 8; монетизация 7; простота 8; масштабируемость 7.

## Концепт №9. «Снос Ltd.» (физическое разрушение + контракты + инструменты)

**Возвраты:** «почти получилось» — ретрай-петля; коллекция инструментов; районы города как карта прогресса; режим песочницы (свободное разрушение — доказанный формат Melon Sandbox 115 тыс. оценок); ежедневный «объект дня».

**Почему ЯИ:** физический краш-фан доказан топами (Смертельный Спуск 127 тыс. оценок/2 года — факт); мужская аудитория + дети; короткие попытки = плотная реклама без нарушения правил (после попытки — экран результата); 2D-физика доступна соло.

**Монетизация:** rewarded — дополнительная попытка, удвоение оплаты, «супер-инструмент» на один контракт, страховка провала; interstitial — между контрактами; IAP позже.

**MVP (6–8 недель):** 2D-физика (matter.js/Unity 2D), 10 разрушаемых объектов (балочно-блочная конструкция), 4 инструмента, 20 контрактов, песочница, RU+EN.

**Развитие:** 1.1 — 6 новых инструментов, районы, «точные» контракты (снести трубу, не задев дом); 1.2 — объект дня, комбо-разрушения, апгрейд базы фирмы; 2.0 — 3D-режим (Unity), мульти-объекты, сезонные события.

**Сложность:** программирование 7 (стабильность физики, детерминизм для лидербордов); графика 5; контент 5; backend 1; техника 6 (производительность на слабых устройствах); **объём 6/10**.

**Потенциал:** привлечение 8; удержание 7; монетизация 8; простота 6; масштабируемость 7.

## Концепт №10. «Золотой матч» (ретро-футбол: менеджмент + аркадные матчи)

**Hook:** Retro Bowl для дворового футбола: вы — тренер команды из ЖЭКа, ведёте её от дворовой лиги к кубку — короткие аркадные матчи + состав, тренировки и трансферы между ними.

**Возвраты:** сезонная структура (месяцы игры — доказано Retro Bowl, топ Poki), рост игроков и команды, трансферный рынок (переменная награда без гэмблинга), таблицы лиги, история клуба (статистика сезонов).

**Почему ЯИ:** спорт в топах западного веба (Retro Bowl, Basketball Stars — факт), на Яндексе глубокого менеджмента нет (наблюдение); мужская аудитория 42% + подростки; матчи дискретны = compliant-реклама; долгая жизнь без контента-гонки (сезоны генерируются).

**Монетизация:** rewarded — удвоение приза, бесплатный трансфер-слот, скаут (разведка игрока), доп. тренировка; interstitial — после матча/между сезонами (естественные паузы); IAP — форма/гербы (косметика), «золотой сезон».

**MVP (8–12 недель — самая дорогая концепция списка):** матч 5×5 на полполя с тайминг-управлением, лига 12 команд, состав 8 игроков с параметрами, тренировки, 1 дивизион, RU+EN.

**Сложность:** программирование 8 (ИИ матча + менеджмент-системы); графика 6 (пиксель-арт прощает, но анимации нужны); контент 6; backend 1; техника 6; **объём 7/10**.

**Потенциал:** привлечение 7; удержание 9 (максимум в списке); монетизация 8; простота 4; масштабируемость 8.

## Концепт №11. «Остров нанограмм» (нонограммы + восстановление острова)

**Hook:** Нанограммы, которые рассказывают историю: каждая решённая картинка открывает фрагмент заброшенного острова и его тайну — проверенная головоломка + коллекционно-нарративная мета по модели «Тайны особняка», но в свободной нише.

**Loop:** выбрать «раскоп» → решить нанограмму → открылся фрагмент острова/артефакт → бит сюжета (3–4 предложения) → новая зона → крупнее/сложнее нанограммы → остров восстанавливается визуально.

**Возвраты:** видимое восстановление острова (коллекционный прогресс), интрига истории, «мини-нонограмма дня» + стрик, цветные нанограммы как поздний апгрейд.

**Почему ЯИ:** головоломки — ядро платформы; 45+ женская аудитория; merge-нарративная модель доказала, что «пазл + история» монетизируется и удерживает (Тайна Особняка — факт), а ниша нанограмм с нарративом свободнее merge (наблюдение); контент дёшев — нанограммы генерируются алгоритмом с ручной фильтрацией.

**Монетизация:** rewarded — подсказка (открыть клетку), прощение ошибки, энергия, удвоение монет; interstitial — между головоломками; IAP — отключение рекламы, бонусные главы.

**MVP (4–5 недель):** генератор + 100 отобранных нанограмм (5×5…15×15), 1 остров (30 фрагментов), минимальный сюжет, энергия, «головоломка дня», RU+EN.

**Развитие:** 1.1 — второй остров, артефакты-коллекция, стрики; 1.2 — цветные нанограммы, события; 2.0 — кампания по сезонам, «экспедиции» (наборы связанных головоломок), турниры.

**Сложность:** программирование 4; графика 4; контент 3 (генерация + редактура); backend 1; техника 2; **объём 4/10** — самая дешёвая концепция списка.

**Риски:** нанограммы — красный океан без меты (дифференциация только историей/островом); генератор должен выдавать однозначно решаемые и «красивые» картинки; нарратив дешёвый, но некачественный текст убьёт атмосферу.

**Потенциал:** привлечение 6; удержание 7; монетизация 7; простота 8; масштабируемость 6.

## Концепт №12. «Тренд-сёрфинг» (конвейер быстрых мем-игр) — тактическая стратегия

**Hook:** Не одна игра, а пайплайн: шаблон кейс-сима/арены/обби + скин свежего мема (как «Мусор Дроп» — ≥3 клона за 10 дней, факт) — релиз за 1–3 недели на пике TikTok-волны, максимум рекламы, следующая волна.

**Loop (игрок):** открывать кейсы/собирать мем-существа/проходить мини-обби → коллекция → рейтинг. **Loop (разработчик):** мониторинг трендов (TikTok/Roblox/YouTube) → выбор волны → рескин шаблона → релиз в первую неделю тренда → агрессивная монетизация → поддержка 2–6 недель → следующий тренд.

**Возвраты (игрок):** коллекция мем-предметов, рейтинг; жизненный цикл короткий (недели).

**Почему ЯИ:** рекомендационная система оценивает новинку за неделю и даёт трафик при хороших метриках (факт) — быстрые релизы ловят волну спроса; доказано топами (кейс-симы, brainrot-игры, «Укради Яйцо!» 88/99 за 16 дней).

**Монетизация:** максимально плотная в рамках правил: rewarded (бесплатный кейс/спин/существо), interstitial между открытиями, sticky.

**MVP:** переиспользуемый шаблон (кейс-сим: 2–3 недели первой версии; дальше рескины по 5–10 дней).

**Развитие:** библиотека шаблонов (кейс-сим → арена-автобаттлер → merge → обби), A/B иконок, быстрый локал RU/EN.

**Сложность:** программирование 3 (после шаблона); графика 4; контент 3; backend 1; техника 3; **объём 3/10** на релиз после шаблона.

**Риски:** жизнь тренда — недели (доход нестабилен); **IP-риски**: реальные скины/персонажи/бренды могут привести к снятию игры (факт — ответственность на разработчике с 05.2026); гонка клонов (кто не первый — тот не заработал); репутационный потолок (игроки и платформа ужесточают отношение к низкокачественному контенту — тренд модерации 2025: снос «Имитаций»); это **тактика кэш-флоу, а не стратегия**.

**Потенциал:** привлечение 9 (в окне тренда); удержание 3; монетизация 7; простота 8; масштабируемость 4. **Рекомендуемое использование:** как побочный конвейер (20–30% времени) параллельно основной «вечной» игре, с осторожностью к IP.

## Концепт №13. «Космо-лом» (разделка дереликтов: физика резки + коллекция + станция)

**Hook:** Вы космический старьёвщик: режете брошенные корабли на модули (таймер кислорода!), а из добытого строите собственную станцию и узнаёте истории погибших судов — физическая резка + коллекция + базостроение.

**Loop:** выбрать дереликт на карте сектора → вход: резка обшивки (свайп-линии, физика распада, лимит кислорода/топлива) → добыть модули и артефакты → продать ИЛИ достроить свою станцию (видимый рост) → новые секторы/инструменты резки → более крупные и опасные корабли.

**Возвраты:** станция растёт на глазах (визуальный прогресс + idle-доход модулей), артефакты-коллекция с микро-историями (бортовые журналы), сектора как карта открытий, ежедневный «сигнал бедствия» (бонусный дереликт), апгрейды резаков.

**Почему ЯИ:** механика резки понятна за секунду (Cut the Rope-грамотность аудитории); физика+коллекция — сочетание, которого в топах нет (наблюдение); космос универсален для RU/EN (40% аудитории — мир); забеги по 2–4 минуты = compliant-реклама; 2D-реализация доступна соло.

**Монетизация:** rewarded — дополнительный кислород, удвоение добычи, аварийная эвакуация с грузом, бесплатный «сигнал дня»; interstitial — между вылазками (экран ангара = неигровое действие); IAP — скины станции, отключение рекламы.

**MVP (6–8 недель):** резка полигональных корпусов (2D-физика разреза — самая сложная часть; упрощение: корпус = набор скреплённых блоков, «резка» = разрушение связей свайпом), 8 процедурных дереликтов из блоков, станция из 6 модулей, 3 инструмента, RU+EN.

**Развитие:** 1.1 — бортовые журналы (нарратив), редкие артефакты, аукцион добычи; 1.2 — сектора с фракциями, ежедневные сигналы, апгрейд-древо; 2.0 — «живые» дереликты (мини-события внутри: дроиды, ловушки), режим экспедиции.

**Сложность:** программирование 7 (физика разреза/распада — рискованный модуль, нужна ранняя проверка fun'а); графика 5; контент 5; backend 1; техника 5; **объём 6/10**.

**Риски:** физика резки может «не сложиться» feel'ом (митигация: прототип механики в первую неделю — kill-criterion); тема чуть дальше от массовой аудитории 45+; конкуренты-песочницы (Melon Sandbox) оттягивают «техно-детей».

**Потенциал:** привлечение 7; удержание 8; монетизация 7; простота 6; масштабируемость 7.

# Финальные выводы

## 1. Наиболее перспективные механики для браузерных игр сейчас

**[НАБЛЮДЕНИЕ на основе всех исследований]:**
1. **Переменная награда + коллекция** (box opening, гача-лайт) — сильнейший доказанный драйвер трафика Яндекса 2024–2026.
2. **Merge как компонент гибрида** — волна растёт, чистые клоны уже конкурируют друг с другом.
3. **Простая аркада + численная/мета-прогрессия** (hybrid-casual) — отраслевой стандарт удержания (D7 ~15–20% против 5–8% у чистого HC).
4. **Ежедневность** (план/лот/нонограмма дня + стрики + лидерборд) — то, что превращает игру 45+ в привычку на годы.
5. **Физический фан с целями** (краш/разрушение/спуск) — высокий CTR и ретраи, но требует «feel».
6. **Короткий раунд (2–5 мин) как единица всего** — и удержания, и легальной рекламной монетизации.

## 2. Что особенно подходит небольшому разработчику

UI-driven жанры без физики и сети: кейс-опенинг/коллекции, merge, карточные решения, словесные игры, нанограммы, idle-менеджмент. Контент data-driven (JSON-каталоги), арт стилизованный, сохранения — облако SDK (200 КБ достаточно), backend не нужен. Оптимальный стек: TypeScript + PixiJS/Phaser или Defold/Construct 3; цель по весу — загрузка <4 с.

## 3. Перегретые направления

Обби/Roblox-клоны и имитации (вычищены модерацией и/или ~600 новинок в неделю), чистые кликеры, гиперказуал без меты («красная» кривая трафика по документации платформы), кроссворды/пасьянсы без дифференциации (6-летние лидеры), мем-клоны на поздней стадии тренда, реалтайм-.io для соло.

## 4. Недозаполненные ниши

(а) box opening/коллекционирование, тематически рассчитанное на 30–60; (б) оптимизация/автоматизация (конвейеры, маршруты) для десктопной аудитории; (в) спорт-менеджмент с сезонами (Retro Bowl-модель) — отсутствует; (г) нарративные микро-игры (Reigns-like); (д) cozy-коллекционирование с глубокой метой (рыбалка-экспедиция, приют, музей); (е) гибриды merge+X.

## 5. Топ-5 к рассмотрению в первую очередь (спрос + удержание + монетизация + простота)

1. **«Лавка древностей: Тайные ящики»** (8.0) — максимум доказательств спроса + лучшее соответствие рекламным правилам + solo-friendly.
2. **«Зельеварня»** (7.55) и **«Глубина»** (7.55) — безопасные растущие ниши (merge-менеджмент; коллекционная рыбалка), умеренная конкуренция.
3. **«Бастион»** (7.45) — максимальная монетизация забегами; чуть сложнее в разработке.
4. **«Словарь забытых слов»** (7.45) — самый дешёвый вход в доказанную «вечную» нишу словесных игр с ежедневностью.

### Краткие планы MVP

- **Лавка древностей (4–6 нед.):** аукцион-экран → покупка ящика → открытие с анимацией редкости → 2 мини-игры реставрации → продажа/альбом (40 слотов) → 3 апгрейда → daily-лот → облако + лидерборд «состояние» → RU/EN, 60 предметов.
- **Зельеварня (4–6 нед.):** merge-доска 6×8 (30 предметов, 6 цепочек) → клиенты-заказы (8 зелий) → монеты/репутация → 5 апгрейдов лавки → книга рецептов → daily-заказ → RU/EN.
- **Глубина (4–6 нед.):** тайминг-заброс + вываживание → 25 рыб (3 редкости) → энциклопедия с сетами → 6 апгрейдов снастей → 1 озеро + 1 скрытая зона → RU/EN.
- **Бастион (6–8 нед.):** стена + доска merge 4×6 → 5 пушек × 3 уровня → 15 волн на забег → 10 мета-апгрейдов → экран результата (revive за rewarded) → лидерборд волн → RU/EN.
- **Словарь забытых слов (4–6 нед.):** слоты-конвейер для букв → валидация слов по словарной базе (200 слов с описаниями) → план дня + лидерборд → 5 апгрейдов → стрики → RU (EN позже).

## 6. Выбор одной концепции для детального проектирования

**Выбор: «Лавка древностей: Тайные ящики»** — не по вкусу, а по явно описанным критериям:

| Критерий (вес) | Обоснование выбора |
|---|---|
| Спрос (25%) | Единственный кластер, представленный **и** в историческом топ-16 (Бравл Бокс 163,7 тыс.; Кейс симулятор Стандофф 2 125,5 тыс.; Кейс-батл 92,1 тыс. — все за 1–2 года), **и** в топ-15 текущего роста (Мой Ресейл: 55,8 тыс. оценок за 11 недель, ~+1000/день; Мусор Дроп: 7,7 тыс. за 10 дней). Ни одна другая механика не имеет такой плотности доказательств на платформе прямо сейчас. |
| Удержание (25%) | Коллекция + переменная награда + ежедневный лот + музей-idle — 4 независимых возвратных механизма; конкуренты («Кейс-батл») держатся в топе год+ на одной лишь коллекции — здесь слой толще (реставрация, заказы, музей). |
| Монетизация (20%) | Box opening даёт наибольшее число органических rewarded-точек (переоткрытие, оценка, страховка, daily) при полностью пошаговом геймплее — максимально compliant с п. 4.4 требований Яндекса; экономика допускает последующий IAP без переделки. |
| Простота для соло (20%) | UI-driven, без физики/сети/backend; главный расход — иллюстрации предметов (стилизация + частично ИИ-арт, разрешён с 05.2026); MVP 4–6 недель. |
| Масштабируемость (10%) | Каталог предметов data-driven; эпохи/музей/аукционные дуэли (призраки) расширяют игру годами. |

**Честные оговорки (не «гарантия успеха»):**
- Ключевая гипотеза — что тема антиквариата/аукционов конвертирует сегмент 30–60 — **не проверена прямыми данными**; проверка дешёвая: A/B иконок и названий в консоли Яндекса (инструмент платформы, факт) + первая неделя метрик.
- Если сегмент не отзовётся, игра остаётся валидной для 18–34 (ресейл/Авито-культура — «Мой Ресейл» это подтверждает косвенно).
- Основной сценарий провала — не «нет спроса», а слабое качество арт-постановки открытий и отсутствие чувства «охоты за редкостью»; это управляется на этапе прототипа.
- Запасной кандидат при провале валидации: «Зельеварня» (тот же пайплайн UI-merge-экономики, переиспользуется до 60% кода — синергия портфеля).

## 7. Архитектура удержания «завтра / через неделю / через 50 сессий» (сквозная для любой концепции)

- **Завтра:** ежедневный бесплатный лот/заказ/план дня + стрик + короткий daily-лидерборд (сброс в 00:00) — причина зайти на 3 минуты.
- **Через неделю:** видимый прогресс коллекции/базы на 60–70% незавершённости (эффект Зейгарник) + еженедельное событие/турнир + открытие нового контента по расписанию (1 новая эпоха/вид/ветка в 1–2 недели).
- **Через 50 сессий:** долгосрочные цели (полный альбом, легендарный предмет, финальная концовка), престиж-механика (сброс с бонусом), асинхронное соревнование (исторические лидерборды, призраки), сезонные коллекции.
- Плюс обязательное: обновления контента видны в описании/карточке — платформа ранжирует по возвращаемости и фичерит живые игры (факт из документации).
