# CITY VISUAL QUALITY REPORT — «Лавка 2.0: Аукцион», v0.7.0-city

Итерация: **полная переработка города** — из «сетки зданий-кнопок» в многослойную живую
2.5D-диораму «маленький район» в едином стиле stylized cozy retro. Логика, экономика,
телеметрия, сохранения и NPC **не тронуты**; новых механик нет. Город остаётся сценой-хабом:
лавка / запчасти / аукцион-склад / гараж / усадьба, клики и блокировки работают как прежде.

Бенчмарк плотности, композиции и читабельности — Bid Wars 2 (город как «витрина прогресса»).
Он использован **только как ориентир плотности и читаемости кварталов**, копирования арта
и механик нет: у нас собственный стиль (вектор, вечерний свет, диорама с кулисами),
собственная структура (рыночная площадь как композиционный центр, улица с движением,
ближний тротуар с горожанами) и собственная динамика (walk-циклы, транспорт, птицы, дым).

## 2. Принципы диорамы

1. **Город — не меню, а район.** Минимум 7 планов по глубине: небо и солнце → дальний силуэт
   города с ориентирами (водонапорная башня, часовая башня, фабрика, шпили) → зелёный склон и
   верхняя улица с дальним рядом домов → средний ряд с дворами (булочная, часовщик, киоск,
   сарай, заборы, бельевые верёвки) → рыночная площадь (фонтан, лотки, флажки) → главный ряд
   (лавка — герой композиции, склад, усадьба, гараж, запчасти) → улица с движением → ближний
   тротуар с горожанами → передний план-кулиса (дерево, фонарь, нос машины, ветка с листьями).
2. **Ориентиры и уличная сеть.** Часовая башня держит вертикаль центра, водонапорная башня и
   фабрика — фланги; клинья переулков сходятся к точке схода `vp=[800,415]` (desktop) /
   `[400,470]` (portrait): площадь, правый и левый переулки, зебры продолжают оси.
3. **Живой слой.** 8 прохожих одновременно (разные позы, темп, направления), дворник с метлой,
   сидящие на скамейках, ребёнок машет, коты, грузовик и легковушки на улице, тележка лавки,
   птицы (стая + воробей у лужи), дым из трубы, пар из люка, облака, качающиеся листья ветки,
   флажки площади, фонтан, качающаяся вывеска-самовар, светящиеся окна.
4. **Свет: низкое вечернее солнце слева.** Длинные тени вправо у зданий (`LongShadow`),
   направленные тени у всей утвари переднего плана (`DirShadow`) и у идущих горожан (тень
   внутри `Walker`), контактные тени (`GroundShadow`), тёплые световые лужи у витрин,
   сумеречный градиент + виньетка + плёночное зерно поверх.
5. **Атмосферная перспектива.** Дальние ряды десатурированы и осветлены градиентами дымки
   (`c-haze`), силуэт города на 32–50% непрозрачности; ближние планы — насыщенные и тёплые.
6. **Diegetic вместо UI.** У входов — нарисованные штендеры-раскладушки («Ваша лавка»,
   «Аукцион», «Запчасти»…), у locked — потускневшие; никаких кнопок-плашек поверх мира.
   Класс `.ui-label` скрывается вместе с UI при `noui=1`.
7. **Locked = физически закрыто.** Щиты на дверях, ставни/решётки на окнах, таблички «ЗАКРЫТО»,
   плюс лёгкий grayscale/brightness фильтр; здание продолжает жить в композиции, но читается
   как «заперто», а не как «выключенная кнопка».
8. **Портрет — отдельная композиция**, а не кроп: вертикальная раскадрова (небо с кулисой →
   дальний план → верхняя улица → средний ряд → площадь → главный ряд с лавкой-героем →
   улица → тротуар → передний газон), свои якоря зданий, свои тайминги транспорта.

## 3. Camera move и отклик

- Клик по зданию: rAF-наезд `.city-pan` (scale 1 → 2.4, ease-in-out cubic) с `transform-origin`
  в точке здания (арт-координаты → % экрана через `useArtMap`), fade сцены после 78% пути,
  затем `game.enterBuilding(id)`. 480 мс в бою; детерминировано (inline-transform на rAF),
  т.к. CSS transform-анимации на SVG-контейнере в headless-shell вели себя нестабильно.
- Hover: brightness + drop-shadow + scale 1.012 (проверено численно: средняя яркость зоны
  лавки на скриншоте hover на +3.6 выше, чем без hover).
- Locked-здания не zoom'ят: сразу `enterBuilding` (там ждёт диалог «закрыто»).
- Dev-QA параметры: `slowzoom=1` (1600 мс), `zoompause=1` (стоп-кадр середины наезда —
  единственное изменение в рантайме ради скриншотов; в бою не используется).

## 4. Фикс-лист итерации (найдено → сделано)

| Проблема | Решение |
|---|---|
| Box-проекция к одной точке схода давала гигантские боковые «клинья» у дальних зданий | Косая 2.5D-проекция: вектор глубины `dv = (t·depth·0.82, −depth·0.5)`, объём лепится тоном |
| У двускатных крыш дыра неба под коньком (не было треугольника фронтона) | Фронтон добавлен в `Shell` для gable |
| Полосы дороги рисовались поверх оснований главного ряда (здания «висели») | Порядок живописи: дорога → ближний тротуар → газон → главный ряд → штендеры |
| Nameplate-таблички тонули в мостовой и читались как UI | Diegetic штендеры-раскладушки у входов (`.ui-label`) |
| В портрете внизу была незаполненная полоса (градиент неба читался землёй) | Передний газон 1210–1400 с изгородями, скамейкой, котом, кустами |
| CSS `.scene.zoom-in` гасил всю сцену города в opacity 0 во время наезда | Исключение `:not(.city-scene)`, наезд переведён на rAF |
| **Дыра внизу desktop-композиции**: верхние слои обёрнуты в `translate(0,-40)`, газон 856–900 уезжал на 816–860, ниже оставался пустой градиент неба | Газон продлён под обёрткой до 948 (после сдвига перекрывает 900), добавлены полосы покоса, тёмная передняя полоса, второй ряд травы и цветы |
| Передний тротуар/газон на крупном плане читались плоскими «полосами-стенами» | Направленные тени вправо (`DirShadow`) у всей утвари и горожан, трещины и листья на плитах, полосы покоса и цветы на газоне, тёмная кромка-водосток у дороги |
| Грузовик был «пустой коробкой» | Доски кузова, светлая кромка борта, стоп-огонь, бампер, шов двери кабины |
| QA-кадр camera move попадал в тёмную фазу смены сцены (латентность headless-скриншота ~1 с) | Dev-параметр `zoompause=1` + отдельный кадр «приезда» в обычной скорости |

## 7. Ассеты, плейсхолдеры, компромиссы

- **Ассеты:** 100% вектор (inline SVG) + CSS-анимации. Ноль растра, ноль внешних шрифтов и
  CDN: единый стиль, мгновенная адаптивность, безопасность для слабых устройств, офлайн.
  Зерно плёнки — data-URI `feTurbulence`.
- **Плейсхолдеры:** в headless-shell символ 🔊 топбара рендерится «тофу» (нет эмодзи-шрифта) —
  дефект окружения снимков, в реальных браузерах нормально; реклама — mock-логи (SDK вне
  среза); звуков города пока нет (аудио — отдельная итерация).
- **Компромиссы:**
  - Ближний тротуар/газон — условные «полосы-элевации» (side-view диорама): плоскоcть
    подчеркнена тенями, трещинами, листвой и покосом, но это не честный план земли;
  - slice-кадрирование на 16:9 режет ~1.6% ширины по краям (сознательно: без letterbox);
  - плотность жизни ограничена 8 пешеходами + 3 машинами одновременно (CPU слабых устройств);
  - 178 KB gzip — весь билд игры; город даёт ~⅓, но отдельного code-splitting сцены пока нет.
