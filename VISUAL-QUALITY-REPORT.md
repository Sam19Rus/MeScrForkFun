# VISUAL QUALITY REPORT — «Лавка 2.0: Аукцион», v0.6.0-vq

Итерация: **полный visual quality pass** без новых механик. Цель итерации — заменить
«технический mockup» на цельную художественную систему уровня небольшой коммерческой игры.

---

## 1. Выбранный visual direction

**Stylized cozy retro 2D/2.5D** — «маленький ретро-город, в котором существует моя лавка»:

- **Палитра** (единая, в `src/art/core.tsx`): тёплые дерево/бумага/латунь (`#c8a97e / #efe3cc /
  #d9b23f`), приглушённые оксид-красный (`#5a1c12`) и тил (`#4f6a6a`), чернильный коричневый
  для теней. Никаких случайных цветов: акценты только латунь (UI/награды) и оксид (драма/аукцион).
- **Свет**: ключевой тёплый слева-сверху + практические источники (люстры, лампы, софит) с
  конусами и glow; холодные сумерки из окон как контрапункт; в каждой сцене свой световой сценарий
  (зал — софит на лот, лавка — уютные лампы, мастерская — локальная лампа над предметом,
  город — вечернее солнце с длинными тенями).
- **Форма**: объём лепится тоном (highlight/core shadow), а не контуром; тонкий селективный
  лайн-арт только у персонажей и предметов; архитектура — без обводок.
- **Глубина**: минимум 3 плана в каждой сцене + атмосферная перспектива (дальний город
  десатурирован), кулисы/силиэты голов/ветки в переднем плане, перекрытия и масштаб.
- **Материалы**: общие градиенты/паттерны (`g-wood`, `g-brass`, `g-steel`, `g-glass`, `g-bak`,
  `p-brick`, `p-floor`) — дерево ≠ металл ≠ стекло ≠ ткань визуально.
- **Плёнка**: поверх всех сцен — зерно (data-URI feTurbulence) и виньетка: мир, а не веб-страница.

Технология: **вектор (inline SVG) + CSS-анимации**, без растра и без 3D: единообразие стиля,
мгновенная адаптивность, малый вес (bundle ~143 KB gzip), безопасность для слабых устройств.

## 6. Технические компромиссы

1. **SVG-координаты вместо DOM-раскладки**: зал/город собираются в одном viewBox 1600×900
   (`preserveAspectRatio: slice`), чтобы персонажи, лот и свет не расслаивались; HTML-оверлеи
   (теги лотов, портретные фигуры) позиционируются через пересчёт координат сцены в % (`useSceneMap`).
2. **Portrait**: не даунскейл, а перекомпозиция — суженный viewBox (зал 940→центр, город 400),
   свои якоря столов/зданий/реквизита; фигуры и таблички в portrait — HTML-оверлей
   (надёжнее вложенных svg при crop).
3. **CSS transform-box: fill-box** для суставов персонажей (плечо/локоть/голова) — независимость
   от вложенных трансформов; переходы эмоций 250–300 мс.
4. **Производительность**: один feTurbulence-слой на сцену через CSS data-URI (кешируется),
   градиенты/паттерны общие на документ (монтируются один раз), анимации — только transform/opacity,
   частиц немного (пылинки софита, дым, пар). Bundle ~143 KB gzip.
5. **Вложенные svg-ящики** (PACK_SVG) получают явные width/height при вставке в сцену —
   иначе nested-svg растягивается на весь viewport (найденный и исправленный баг).
6. Headless-скриншоты: chrome-headless-shell (полный chrome в песочнице ловит V8 OOM);
   emoji-тofu в контейнере больше не влияет на проверку, т.к. emoji выведены из UI.
